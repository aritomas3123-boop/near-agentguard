NEAR Hackathon candidate / audit build

AgentGuard.

A testnet-only contract proof built and unit-tested in an isolated Render build. Its rules cap proposed spending, reject nonce replay, restrict recipients and record human review.

What this deployment proves

  • Rust source compiled into a NEAR-compatible WebAssembly artifact.
  • Automated unit tests were executed during container build.
  • A SHA-256 checksum is available from the health endpoint.
  • No wallet, signing key, real funds or token transfers exist on this service.

Security & limitations

Not deployed on the NEAR blockchain. On-chain enforcement and a verifiable NEAR testnet transaction remain separate acceptance gates. A successful build is not a completed hackathon submission.

The interactive sandbox is hosted separately and is private until reviewed. The linked source is public for code audit.
